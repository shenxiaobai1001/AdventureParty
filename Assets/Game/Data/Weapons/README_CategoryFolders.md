# 武器物品文件夹 = WeaponCategory（武器=武艺）

把武器 `.asset` / 图标放进对应类型文件夹。投掷、武术无物品文件夹。短刃/匕首模型归 **Sword**。

| 文件夹 | 含义 | 占手 |
| --- | --- | --- |
| Sword | 单手剑（含短刃） | 单手 |
| GreatSword | 巨剑 | 双手 |
| Hammer | 单手锤 | 单手 |
| GreatHammer | 重锤 | 双手 |
| Axe | 单手斧（重、非开刃） | 单手 |
| GreatAxe | 巨斧 | 双手 |
| Spear | 长枪 | 双手 |
| Staff | 法杖 | 右手+锁左手 |
| Shield | 盾 | 仅左手 |
| Bow | 弓 | 双手 |
| Crossbow | 弩 | 双手 |
| LongGun | 长火枪 | 双手 |
| ShortGun | 短火枪 | 单手 |

法杖场景预制体：`Assets/Game/Prefabs/Weapons/Scene/Staff/`

UI 节点（`UIStatePanel`）：Sword / Greatsword / Hammer / HeavyHammer / Axe / HeavyAxe / LongHandled / Wand / Bow / Bolt / Longgun / Shortgun / Shield / Throw / Wushu
